# Hierarchical clustering

This analysis performs hierarchical clustering of the 56 *Plasmodium vivax* isolates using the pairwise SNP allele-sharing distance matrix generated by [`pairwise_snp_allele_sharing_distance.R`](../pairwise_allele_sharing_distance/pairwise_snp_allele_sharing_distance.R).

In the manuscript workflow, this script is a downstream analysis of the pairwise genetic distance matrix. It supports the Results section by visualizing how isolates cluster according to genome-wide SNP allele sharing, and whether traveler-associated infections form separate groups or cluster with infections from the sampled communities.

## Script

```text
hierarchical_clustering.R
```

## Input files

The script uses:

```text
results/pairwise_allele_sharing/pairwise_distance_matrix.tsv
data/analysis_ready/pv_56samples_metadata.tsv
```

The distance matrix contains pairwise genetic distances calculated as:

```text
distance = 1 - PS
```

where `PS` is the pairwise SNP allele-sharing similarity. The allele-sharing calculation is performed in `pairwise_snp_allele_sharing_distance.R`; this clustering script only reads the completed distance matrix.

The metadata file is used to add community and travel-status information to the dendrogram. The script accepts `Sample`, `sample`, or `id` as the sample identifier column. The metadata must also contain `community` and `travel` columns.

## Method

The script reads the completed pairwise distance matrix and matches it to the sample metadata. Sample IDs ending in `.GT` are cleaned before matching, so the distance matrix and metadata use the same sample names.

Hierarchical clustering is then performed using average linkage:

```r
hclust(as.dist(dist_mat), method = "average")
```

Average linkage clusters samples according to the average pairwise distance between groups. Here, the distance is `1 - PS`, so samples with more similar SNP allele-sharing profiles cluster closer together.

The dendrogram is cut into four groups using:

```r
cutree(hc, k = 4)
```

The value `K = 4` is used as a descriptive cut of the dendrogram for the manuscript figure and cluster-assignment table. It does not determine the dendrogram topology; the topology is determined by the average-linkage clustering from the full pairwise distance matrix. The `K = 4` cut is applied after clustering to summarize the four main dendrogram groups shown in the manuscript and to export a simple cluster label for each sample.

The dendrogram height is transformed with a fourth-root scale for plotting:

```r
hc_plot$height <- hc$height^(1 / 4)
```

This transformation is used only to improve visual separation of branches in the figure. It does not change the clustering, the sample order, or the cluster assignments.

Samples are colored by community:

```text
Libertad      = blue
Gamitanacocha = green
Urco Miraño   = orange
```

Traveler-associated infections are marked with a cross on the dendrogram tips. This annotation is used to show whether traveler-associated infections cluster separately or are embedded among infections from the same communities.

## Outputs

Outputs are written to:

```text
results/hierarchical_clustering/
```

The main outputs are:

```text
hierarchical_cluster_assignments.tsv
hierarchical_clustering_k4.pdf
hierarchical_clustering_k4.png
```

`hierarchical_cluster_assignments.tsv` contains the sample ID, cluster assignment, community, and travel-status annotation for each sample. The PDF and PNG files contain the plotted dendrogram with community colors, traveler markers, and rectangles showing the four dendrogram groups.
